Wx411Easy 1.5 RC9 中文验收步骤
=============================

测试前
------
1. Windows 10/11 x64；右键 RC9 EXE，选择“以管理员身份运行”。
2. 完全退出目标程序，包括托盘，确认没有 `Weixin.exe`。
3. 目标进程保持“自动捕获全部 Weixin.exe”。
4. 选择一个数据库作为 PID 优先库；列表中的全部发现数据库都会参与匹配。
5. 使用新的空输出目录。

第一轮：取消证据
----------------
1. 先点击“定位 key 并解密”。
2. 再启动目标程序，等待“Weixin.dll 已加载，已同时设置 4 个观察点”。
3. 在进程等待、模块等待、观察点设置完成或监听阶段点击“取消”。
4. 等待界面显示“已取消”，确认输出目录没有临时文件。

第二轮：真实捕获
----------------
1. 完全退出并重新启动目标程序。
2. 再次先点击“定位 key 并解密”，再启动目标程序。
3. 等 4 个观察点设置完成后登录。
4. 访问聊天、图片、语音、视频和联系人资料页，覆盖不同数据库业务。
5. 保持工具和目标程序开启，等待逐库导出完成。
6. 输出完成后点击“导出证据包”。

日志判断
--------
- `数据库总数=18; 已暂存=12; 尚未命中=6` 表示 18 个已发现，12 个已进入 pending，6 个尚未命中。
- “新增 N”表示监听期间出现新 `.db`。
- “换代 N”表示已有路径的文件代际变化，通常来自登录期写入、截断或替换。
- “逐页认证和 integrity_check 完成”才表示该数据库成功。
- WAL 持续写入时，工具会读取最后连续有效 commit；失败数据库不会阻断其它数据库。

通过标准
--------
1. 界面只有“定位 key 并解密”这一条恢复入口，没有旧扫描或固定 30 秒流程。
2. 至少一个 `*.readable.sqlite` 通过逐页认证和 `integrity_check`，Gate B 为 PASS。
3. 取消轮目录清洁，后续运行确认 pending 票据未复用，Gate C 为 PASS。
4. Gate A 为 N/A；Gate D 只观察源文件变化。
5. Gate B 与 Gate C 均为 PASS 时，总结果为 PASS。

未命中数据库
------------
- `media_0`、`bizchat`、`weclaw` 等库需要再次访问对应业务。
- 未命中只影响该库，不影响已经完成的副本。
- RC9 不实现关闭程序后的跨启动后台续跑。

本轮已验证基线
--------------
- 18 个发现数据库，13 个成功输出，5 个未命中。
- 输出失败 0 个，临时 `*.tmp-wal`、`*.tmp-shm` 残留 0 个。
- Gate B/C PASS，总结果 PASS。
