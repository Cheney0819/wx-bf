# 独立一键卸载工具设计

## 目标

提供一个独立发布的 `一键卸载.exe`，用于彻底移除桌宠 EXE 软件安装时写入的文件与系统入口。用户双击该工具后，工具自动停止属于目标安装目录的桌宠后台进程，执行匹配的安装包卸载流程或清理解压版安装目录，并在全部清理项通过验证后显示成功结果。

工具本身位于独立工程与独立发布目录，可从桌面、下载目录或任意其他位置运行；删除目标桌宠目录时不会影响工具自身执行。

## 范围

### 清理目标

- 桌宠主程序和位于目标安装目录内的全部子进程。
- 安装目录内的全部文件与子目录。
- 指向目标桌宠可执行文件的桌面、开始菜单和启动目录快捷方式。
- Inno Setup 安装记录对应的标准卸载器与卸载注册信息。
- 现有直接安装位置 `%LOCALAPPDATA%\JunjieeDesktopPet`。

### 范围外

- 不终止位于其他目录的同名进程，例如其他软件使用的 `ffmpeg.exe`。
- 不删除目标桌宠以外的软件文件、快捷方式或注册信息。
- 不处理 Windows 自身的系统事件、下载历史或还原点等系统记录。

## 工程与发布

新增独立 .NET 8 Windows 工程：

```text
tools/DesktopPet.Uninstaller/
  DesktopPet.Uninstaller.csproj
  Program.cs
  Services/
    InstallLocator.cs
    ProcessShutdownService.cs
    ShortcutCleanupService.cs
    UninstallExecutor.cs
    VerificationService.cs
```

项目发布为单文件 Windows EXE，名称固定为 `一键卸载.exe`。该项目不引用 `windows-pet-wpf` 的界面、聊天、语音或微信处理代码。

工具提供简洁状态窗口：开始后依次显示“定位安装目录”“退出后台进程”“清理安装入口”“删除文件”“验证结果”；成功后显示“卸载成功”，失败时显示未清理的具体路径或步骤及可复制的诊断信息。用户启动工具即开始清理，不设置额外确认步骤。

## 目标定位

定位优先级如下：

1. 命令行参数 `--install-dir <路径>`，并验证其中存在预期的桌宠主程序。
2. 读取 Inno Setup 的卸载注册信息，在当前用户与本机、32 位和 64 位注册表视图中匹配桌宠固定 `AppId` `{8D5C4C3A-9F3E-4BA3-A8F1-35D3C86A7C11}` 与显示名称。
3. 回退到 `%LOCALAPPDATA%\JunjieeDesktopPet`，并验证主程序存在。

发现多个有效候选安装时，界面列出完整路径供用户选择；没有有效候选安装时，显示“未发现可卸载的桌宠安装”，且不进行删除。

## 卸载流程

1. 解析并规范化目标安装路径，拒绝根目录、用户主目录及无法验证为桌宠安装的位置。
2. 枚举桌宠进程与其后代进程。仅结束主模块路径在目标安装目录中的进程；子进程按父子关系一并退出。
3. 等待进程退出与文件锁释放，超过超时后列出仍在运行的进程与文件路径。
4. 枚举桌面、开始菜单和启动目录的 `.lnk` 文件，解析其真实目标，只删除目标在安装目录内的快捷方式。
5. 若找到目标对应的 Inno 卸载命令，先验证注册表中的 `UninstallString` 可执行文件是目标目录内的 `unins*.exe`，再启动并等待完成，使其移除注册信息和安装文件；没有经过验证的命令时不猜测目录中的其他可执行文件，直接报告失败。
6. 再次清理已确认指向目标目录的快捷方式。
7. 验证安装目录、当前用户及公共 Desktop/Programs/Startup 中的目标快捷方式，以及 AppId 且 `Inno Setup: App Path` 等于所选目标的卸载注册记录均已消失。
8. 仅当所有验证项通过时显示“卸载成功”并返回退出码 `0`；任一清理或验证失败时返回非零退出码并显示失败详情。

## 进程与路径安全边界

进程匹配以完整可执行文件路径和父子关系为准，不按镜像名称全局结束。路径比较使用规范化后的完整路径和 Windows 不区分大小写规则；所有待删除路径必须位于经验证的安装目录内，快捷方式则必须解析到该目录内的实际目标。

工具在调用 Inno 标准卸载器前保留其所在文件；清理解压版时由独立工具删除安装目录，因此不会发生卸载器删除自身后中断的问题。

## 失败处理

- 进程在超时后仍未退出：不继续删除被占用文件，显示进程名、PID 与路径。
- Inno 卸载器返回失败码：保留其退出码与目标目录状态，报告失败。
- 文件删除失败或验证发现残留：报告残留的文件、快捷方式或注册表位置，返回非零退出码。
- 没有发现有效安装：不执行删除，返回非零退出码。

## 验收标准

- 从桌面或下载目录双击独立 `一键卸载.exe` 可卸载安装包版桌宠。
- 卸载前运行中的桌宠主程序、解密器和安装目录内子进程全部退出；其他目录中的同名进程保持运行。
- 桌面、开始菜单和开机启动中的目标快捷方式被移除；其他软件快捷方式不受影响。
- 安装包版完成后，安装目录和对应卸载注册记录均不存在。
- 解压版或直接安装版完成后，目标安装目录和相应快捷方式均不存在。
- 任一残留项或失败步骤均不显示“卸载成功”，并给出可定位的失败信息。
