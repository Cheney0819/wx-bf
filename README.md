# Footprint

本地微信聊天记录导出与浏览工具，帮助用户备份和查看自己设备上的微信数据。

## 功能简介

Footprint 是一个本地工具，用于从您自己的电脑上导出微信聊天记录，并提供便捷的浏览界面。

**支持的数据类型：**

| 类型 | 说明 |
|------|------|
| 聊天消息 | 个人和群聊的文本消息 |
| 联系人 | 昵称、备注、群成员信息 |
| 图片 | 聊天中收发的图片 |
| 语音 | 聊天中收发的语音消息 |
| 收藏 | 收藏的文本、链接等内容 |

## 使用方式

1. 在 Windows 上运行主程序
2. 程序会自动识别本地微信数据
3. 导出完成后，可通过本地浏览器查看聊天记录

## 技术栈

- C# / .NET 8
- SQLite 数据库解析
- 本地 Web Viewer

## 项目结构

```
src/Footprint/
  Footprint_Core/        核心逻辑
  Footprint_Capture/     数据采集
  Footprint_Parser/      数据解析
  Footprint_Renderer/    本地浏览界面
  Footprint_Receiver/    数据接收处理
  Footprint_Archive/     归档管理
  Footprint_Media/       媒体文件处理
```
