## 桌宠独立卸载工具

在 Windows 上执行仓库根目录的 `build-uninstaller.ps1` 后，独立的 `一键卸载.exe` 会输出到 `publish-uninstaller/`。该工具可从任意目录运行：它会定位桌宠安装目录、退出该目录中的后台进程、清理快捷方式与开机启动入口、删除安装文件，并显示最终验证结果。

如需指定安装路径，运行：

```powershell
.\一键卸载.exe --install-dir "C:\Path\To\JunjieeDesktopPet"
```

若检测到多个历史安装目录，窗口会要求选择目标路径。通过 `桌宠安装包` 安装的版本也由该独立工具处理：工具读取固定 AppId 对应的安装目录和 Inno `UninstallString`，仅在命令实际位于所选目录内且文件名为 `unins*.exe` 时启动标准 Inno 卸载器。Windows 的“应用和功能”入口仍可按原方式使用。

如果直接从待删除的安装目录内启动 `一键卸载.exe`，它会先复制到临时目录并启动工作进程；原始引导进程只负责交接并以退出码 `2` 退出（这不是最终卸载结果）。临时工作进程会等待引导进程退出，显示最终结果，并以 `0`（成功）或其他非零码（失败）退出。
